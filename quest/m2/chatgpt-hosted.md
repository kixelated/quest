# [M] Use ChatGPT for web login and cloud runners

## Goal

Contributors sign in to the web UI with ChatGPT and fund cloud runner jobs
from their ChatGPT plan. This works within OpenAI's terms for hosted apps.

## Plan

This is conditional future work, not an assumption about current eligibility.
Own-machine runners already use ChatGPT plans locally through the m0
opencode adapter; this quest covers web login and hosted use only. Verify current provider requirements
and supported integration once approval is available.

## Required

- [ChatGPT approval](/quest/m2/chatgpt-waitlist.md) - OpenAI must approve hosted use
- [Cloud runners](/quest/m2/cloud/README.md) - the hosted runs this funds
