# Later work

## Goal

Extend Quest beyond the initial release: hosted ChatGPT funding, planning in
the web UI, and isolated donor runners for Quest on Cloudflare, and native
Windows support.
This act is future work and does not gate the first public release.

## Required

- [ChatGPT login and hosted runs](/quest/a1/chatgpt-hosted.md) - sign in with ChatGPT and fund Sandbox runs from a ChatGPT plan
- [Plan in the web UI](/quest/a1/plan-ui.md) - run quest-plan interviews as interactive prompts on the board
- [Donor isolation](/quest/a1/donor-isolation.md) - runner jobs in microVMs so untrusted donors can contribute machines
- [Native Windows support](/quest/a1/windows.md) - install and use Quest without requiring WSL
- [ChatGPT approval](/quest/a1/chatgpt-waitlist.md) - OpenAI approves hosted Sign in with ChatGPT
