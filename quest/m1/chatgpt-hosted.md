# [M] Use ChatGPT for web login and hosted runs

## Goal

Contributors sign in to the web UI with ChatGPT and fund hosted Sandbox runs
from their ChatGPT plan. This works within OpenAI's terms for hosted apps.

## Plan

This is conditional future work, not an assumption about current eligibility.
The initial hosted service uses Claude API keys; no local or hosted ChatGPT
funding is shipped by that milestone. Verify current provider requirements
and supported integration once approval is available.

## Required

- [ChatGPT approval](/quest/m1/chatgpt-waitlist.md) - OpenAI must approve hosted use
- [Kix decision UI](/quest/m0/kix/README.md) - the app this extends
