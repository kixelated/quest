# Quests

## Goal

Make Quest a reusable way to plan and coordinate repository work through
versioned Markdown, with a standalone CLI and a reversible adoption path.

## Plan

`m0` is the first public release; `m1` holds later work. Add `m2` and later
horizons when concrete work warrants them, keeping milestone numbers stable as
earlier milestones complete.

## Required

- [M0: First public release](/quest/m0/README.md) - install, set up, work, and leave, driven from one pinned binary, launched with Quest on Cloudflare
- [M1: Later work](/quest/m1/README.md) - ChatGPT-funded hosted runs and native Windows
